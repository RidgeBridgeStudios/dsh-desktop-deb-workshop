# Session Discipline: Moderate Ponytail & Caveman

Enforced across all sessions within this repository:

## Ponytail (Moderate)
- Check YAGNI first before writing code: question whether speculative additions need to exist.
- Standard library and existing platform capabilities over third-party dependencies.
- Reuse existing utilities and patterns in the repository before writing new helpers.
- Fewest files and shortest working diff. Boring over clever.
- Never compromise input validation, security boundaries, or test invariants.

## Caveman (Moderate)
- High-density, professional technical communication across all turns.
- Strip conversational filler, polite intros/outros, pleasantries, and tool-call narration.
- Maintain complete sentences and grammatical clarity to prevent technical ambiguity.
- Code blocks, CLI commands, file paths, and exact error strings remain verbatim.
